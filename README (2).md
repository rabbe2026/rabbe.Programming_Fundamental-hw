# Programming Tasks (Java)

Four small Java programs. Each one reads from standard input and prints to standard output.

| File | Task |
|------|------|
| `Task1.java` | Largest Circle: find the largest radius and how many circles have it |
| `Task2.java` | Residents on a Street: totals and averages for each side |
| `Task3.java` | Student Grades: averages, best student, students with a grade below 5 |
| `Task4.java` | Matrix Diagonals: replace both diagonals of a square matrix with 0 |

## How to run

Java (JDK 11 or newer) must be installed.

```
javac Task1.java
java Task1
```

Then type the input, or use a file:

```
java Task1 < input.txt
```

Example for Task 4:

```
javac Task4.java
java Task4
3
1 2 0
5 1 4
2 2 1
```
